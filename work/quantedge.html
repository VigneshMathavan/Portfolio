OVERVIEW

A Bloomberg Terminal for retail options buyers — built because nothing affordable did this well

Most retail traders make options decisions in isolation — checking one indicator, one chart, one timeframe, with no system connecting the dots. QuantEdge Omega was built to solve exactly that: a Bloomberg-style intraday decision-support terminal for NIFTY, SENSEX, BANKNIFTY, and FINNIFTY options buyers, running a 12-condition signal engine across 7 timeframes simultaneously.

This is a full 0→1 product build — architecture design, backend engineering, ML model training, frontend UI, trade journaling, and a live AI learning loop that improves signal accuracy from every recorded trade. The system does not place orders. Every entry and exit is a conscious decision — the terminal provides the intelligence layer that makes that decision faster and more confident.

THE HONEST CLAIM

"This is not a 90% accuracy system. No retail system is. Realistic target: 55–62% win rate at 1:2 R:R, which is profitable over 50+ trades. A well-tuned rule engine beats gut feel. ML adds +3–5% on top of that."

ARCHITECTURE

How the system is built

01

LAYER 01

Node.js Backend — Signal Engine v2

The core orchestration layer runs a 12-condition rule engine across 3 timeframes (5m + 15m + 1H). It classifies the current market regime into 5 states — trending up/down, ranging, volatile, quiet — and gates signals by time-of-day, IV percentile, OI flow, and directional conviction. Signals are scored as POTENTIAL / LIKELY / STRONG / ELITE and surfaced with full parameter breakdowns across 8 pillars.

02

LAYER 02

Python ML Service — XGBoost + RF + LightGBM

A FastAPI microservice runs three models in parallel: an XGBoost win probability classifier (P(trade wins)), a Random Forest regime classifier (5-state + confidence), and a LightGBM premium predictor (expected % change given spot move, delta, and IV). The 19-numeric + 18 one-hot feature vector is the contract shared between Node and Python — trained on 125,000 seeded backtest signals, then retrained nightly on real trade outcomes.

03

LAYER 03

AI Learning Loop — Factor Correlation Engine

The factor learner runs point-biserial correlation between each pillar's score and actual trade outcomes, computing an adaptive weight multiplier [0.4–1.6] per pillar. Pillars that consistently precede wins get boosted; those that don't get dampened. All 7 pillars are now learned. Nightly retrain at 23:30 IST. The weights are visible in the AI Learning Panel — the system explains its own confidence adjustments.

04

LAYER 04

Decision Intelligence — Exit, Risk, Narrative

Every signal is enriched with: an Exit Intelligence module (T1/T2/SL/Timeout probability + median holding time), a Risk Engine (LOW/MED/HIGH/EXTREME with size recommendations), an Institutional Activity detector (BULLISH/BEARISH from ATM OI walls + volume spikes), and a Narrative Engine that produces plain-English trade explanations — no LLM, template-filled from the live parameter vector.

WHAT'S INSIDE

Every signal contains 15 intelligence layers

Signal enrichment — Each actionable signal carries: 50+ live parameters, per-pillar 0–100 confidence scores, ML win probability, regime classification, 7-timeframe alignment grid, 10-year backtest stats per strategy, OI flow direction, expected move range, IV forecast, premium explosion probability, exit probability estimates, institutional activity verdict, live risk level, and a plain-English narrative.

Chain-Keeper — A persistent background cache polls the option chain every 2 seconds during market hours for all 4 indices. On broker failure it serves last-known-good with a staleness flag. Every signal records a chain snapshot — PCR, Max Pain, ATM IV, OI walls — at the moment of evaluation.

Walk-forward backtester — 125,582 signals seeded across NIFTY + BANKNIFTY + FINNIFTY + SENSEX × 7 timeframes × 13 strategies. Used for initial ML training and factor weight calibration. Real trades retrain the models nightly.
